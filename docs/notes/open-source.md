#community #opensource #code

Open Source is when you share you code in the public to be consumed to somebody else

My history with open source started when I was working in an android app to track sensors information to build a machine learning model

my contribution was inside an issue instead of a pull request

At that time I didn't understand much about git, git workflows, branches and so on and so forth

When I started working on PontoTel I contribute to some angular packages in a more mainstream way.

When starting working in react native (very early, lots of stuff to build), I contribute much more as I just needed to change some code inside node\_modules and send a pull request based on my forks.

I've opened a lot of issues in many repos showing all the "bugs", "problems" and "limitations" that I've found when development Brand Lovers.

We did revamp the react-native-camera based on expo-camera because we needed to do facial recognition on Gol app and rctcamera couldn't handle it. We decided to copy and paste the code (giving attribution to expo), because back them expo-camera was too tight to "expo framework". After all this the RNCamera diverged a lot from expo-camera.

I hope someday they will be joined again.

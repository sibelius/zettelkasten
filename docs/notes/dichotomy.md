Dichotomy is to divide the whole in 2 parts

We have many dichotomies in life and in code

server/client → we want to do some work on the server and some work in the client

sync/async → we want to do some sync work and some async work

build/runtime → we want to do some work at build time and some work at runtime

static/dynamic → we want to some static and dynamic code analysis

preload-prerender/defer load-defer render → we want to preload code and data before we need it, but we want to defer code and data until we need it.

wip/done → we need wip to move forward, but we need to finish the wip to move forward

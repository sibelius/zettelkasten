Human Computation is when you use Humans to perform tasks that humans are better can machine. It is like humans helping computers.

Luis Von Ahn made a lot of programs and games to use human base computation to solve problems where machine is not so goof.

Duolingo knows that the best translators are humans. It sends real text to advanced learners train that are piece of websites, they translated buzzfeed using this strategy.

Google images first version was a game where 2 users without communicate needs to say what is inside an image. After discovering some things inside the image these words become taboo to find more objects and things.

The second version of this game was used to segment images, given a word one user would show part of the image to the other player show tell what you as it.

It also made ReCaptcha where users tell the numbers inside images to handle ocr/ digits recognization.

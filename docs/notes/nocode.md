NoCode is building software using "code" (pure text).

It is a higher level way to build software.

You can build software using pre built building blocks ([The era of Content Builders](./the-era-of-content-builders) ).

You can drag and drop blocks and see they running

They follow WYSIWYG (what you see is what you get).

We have a variety of nocode to build websites: WebFlow, Wix, Canva

For backend the options are more limited: DarkLang

- https://darklang.com/

One benefit if that you don't have the deploy flow anymore, everything will do is deploied already. You just need to move from dev to staging to production.

The feedback loop is much faster.

One drawback is that people without coding background will build back data layers, making the nocode application not scale well.

We can think of nocode as another [Thinking Tools](./thinking-tools), as we can build fast prototipes, and then just join the pieces to build it up.

Steve Jobs said do work backwards

Instead of starting with a technology and see how to sell to customers

Start with customers and see what they need, and what technology fits their needs.

That's way that people struggle with learning by theory.

We can think of theory as the same as technology

We need to work backwards when learning, start with the problem you want to solve.

Them find the right theory that you need to learn to solve the problem.

instead of learning parsers by no reason, wait until the problem shows up for you.

I need to move one package to another, the first thing we need is to understading the imports and exports to make sure we refactor them to the right place.

We need a "parser" to understand raw text.

We also need a subgraph "graph" of dependencies to make sure we move the file and all their dependencies together

My Zettelkasten in Notion

I have a list of notes inside a knowledge base note

All notes are flat, I keep external links and links to other notes inside each note

I create a note with some concepts and then one note per concept

For instance, reading a blog/book I create a note for the book and N notes per each concept

I also have notes about practice.

Practice is the only way to learn about the details of reality [Reality has a lot of details](./reality-has-a-lot-of-details) .

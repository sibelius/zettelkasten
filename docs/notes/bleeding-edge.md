#bleeding edge

Bleeding edge is the state of art of something

It is the new technology

When you focus on bleeding edge (new), you have an advantage as everybody start in a clean slate.

You are not competing with Java developers with 10 or more years of experience

Everybody using React hooks has only a few months of experience, so you can compete fair with them

It also show the value of niche, as most people won't try new tools until they gain traction

It can have a great upside if you are right, but the downside is not big as you can transfer the learning concepts to other projects.

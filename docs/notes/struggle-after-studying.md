I got a new topic to learn.

I read 30 articles based on that topic.

I've skim reading 2/3 books on that subject.

I've watched a few videos on that.

Then, I start a new project to test everything that I've "learned".

I've felt a struggle, like if everything that I thought that I know disappeared.

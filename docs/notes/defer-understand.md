Defer is when you let something to do in the future

When learning something you don’t need to understand everything related to it

You can defer some parts to the future

When learning React, focus on React using create-react-app, an opinionated tool, first.

Defer Babel, webpack.

- https://www.jackfranklin.co.uk/blog/letting-tools-make-choices/

It does not mean that you don’t need to learn these stuff. It means you can go back to them when you get used to that you are learning.

Understanding is overrated, I don’t understand every single detail, I prefer to learn high level concepts first and then deep dive when needed

We can be much more [Productivity](./productivity) when using Keyboard then mouse

Mouse needs to traverse the whole screen to find and click in something

we have an Omnibox/Spotlight to easily find actions and things inside applications

you can do any action from the tip of your keyboard

Open the omnibox and [Search](./search) for any action

it is like a genie lamp with infinite options, you can have any wish in the tip of your fingers

To make this possible we need good [Index](./index-note) to make sure we easily find what we want

we can improve our search using context (current state and also past states), and recent actions/pages/code

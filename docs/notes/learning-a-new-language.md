#learning #language

When I'm learning a new language I try to immerse myself with the language.

I've change my computer, mobile phone, browser and everything to the related language.

I'm using duolingo to learn spanish, I'm not spending many time per day learning spanish, but I'm learning some everyday.

I think consistency is better in the long run.

Learning a new language needs time, as learning everything else

I always try to think in the new language, and if I don't know how to say something in it, I use google translate to help me out.

I also to some dumb stuff as mixing my talk and writing with the new language, so you gonna see me trying to use the new language in my life with my wife and kid when thought they don't understand much about it.

Spanish is "harder" because it is to close to Portuguese, so most people think they don't need to learn it, but it has a lot of nuances.

Languages has also a lot of details that you learn as you use more and more.

We have false cognates that are words that you write in a similar way but means something completely different, so you need to unlearn and let your brain relearn again

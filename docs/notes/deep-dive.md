You can only deep dive if you know how to swim

You can learn advanced stuff if you haven’t mastered the basics

[Defer Understand](./defer-understand)

If you try to deep dive before learning to swimming you drown and feel bad about the learning experience.

When you are at the edge: [Bleeding edge](./bleeding-edge)

You need to deep dive as there is not much in the surface.

You need both holistic and deep dive details views of the problems to provide the best solutions to them.

A holistic only will miss important details that you can only see when you zoom in

If you only focus on small details you will be stuck in a local solution

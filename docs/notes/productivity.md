#productivity #fast

To be productivity we need our workflows to be fast

We also need our workflows to be easy to use

creating a new pull request should be fast

creating a new test should be run

run a test should be fast

iterations should be fast

fast refresh, hot reload enable a fast feedback loop

a fast laptop and mobile phone makes you more productivity

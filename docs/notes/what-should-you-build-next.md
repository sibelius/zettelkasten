bug/feature/refactor

A feature is a new capability to the software

You add features when your software can’t handle some users use case

Improvement: improvements are interactions to make an existing feature better. It can make the feature easier to use. It can make the feature faster to use.

Bug: a bug happens when a feature is implemented and not tested properly, or when some edge cases were not considered.

Refactor: it is when we improve the code structure without changing their behavior

---

First principles first

Instead of build a new feature for each user wish, try to understand the core problem they have in their workflows.

Prefer build low level building blocks features that can be reused in many workflows

Try to solve a set of problems instead just one use case.

Prefer a more generic/extensible feature than a much more specific

Do not build for a single user, build for a group of them

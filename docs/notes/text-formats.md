#content

**Plain Text**

We have a plain text when we don't have any formatting, all text are the same

**Rich Text**

Rich text is when we have formatting for part of the text.

When you enable formatting per part of the text, you need to store text as blocks, and each block has it is own styling.

**Markdown**

Markdown is another text format, with it is own peculiarities.

It has some has predefined "tags" where the user applies format based on text

`## my title` represent a heading 2 text

Markdown is more known by programmers

**How to store rich text data?**

- draft-js uses an json with blocks information
- GraphQL
- Web
- React Native
- Rendered?

**How to present data?**

- You need to process blocks information and output result in html

**Why we need them?**

We need them because users want a rich medium to communicate with other ([Thinking Tools](./thinking-tools) )

It can contains: text, image, video, links, mentions, emojis, gifs and more

If you wanna teach someone something you need to repeat yourself

If you wanna something to stick ([Make it stick](./make-it-stick)), this thing should show up more then once.

When doing UX try to show the same action in different places and context, so you can have more chances of the user using it.

When [Learning a new language](./learning-a-new-language), you need to see the same words and structure more than once to remember then. You also need to see them in different context, in a variety ways.

When learning to solve a problem or coding, you need to solve variety of problems with the same concepts to master it

We pass many different training data to machine learning algorithms so they can learn and learn all the variantions. So you can become invariant to changes, much like SIFT algorithm.

SIFT can detect the same image in different orientation, scale,

You want to be `invariant` to be able to transfer the knowledge to other context.

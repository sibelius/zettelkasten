Buying a course make your feel that you made a real commitment to learn something.

Watching the videos also make you feel you are making progress.

The problem start happening when you try to apply everything that you "learned" in a side project, or real life.

Usually what happens is that things are not so easy as it sounds in a video lesson, you try to setup Webpack and get weird error that didn't show in the video.

Reality has many more details that you can see in video.

All courses are about happy case. The happy case is when everything goes well.

The problem is that not everything goes well at first in real life. As your computer could be a bit difference. The version of the package you are working on is different.

So if courses are not the best way to learn something, what is the best one?

**Better ways to learn something**

Learning and cognitive process has being studied many and many years, and we still do not an answer of how we learn.

One book that has many insights about it is Make it Stick.

- https://www.amazon.com.br/Make-Stick-Science-Successful-Learning/dp/0674729013

You learn better if you connect new concepts to old ones that you know already.

You learn more practicing

#content #builder

## What is Content?

Content is information organized to an audience

## What is a Content Builder?

A content builder is a software that you let organize your content in different ways.

You can present information in different forms, using text with many formatting (bold), using images, using audio (podcasts), using video, using gif, using tables, using text formatting, you can embed content from other websites like twitter, youtube and so on.

Content builder goes from "simple" text editor, to note taking app to mobile site nocode solutions.

## Before content builder?

We have different types of "documents" to present information.

We have Word/Google Docs to present text information.

We have Excel/Google Sheets to present table information

We have Powerpoint/Google Slides to do slides.

What if I want to add some text/paragraph to my sheet?

What if I want to add some slide form to my text document?

## Blocks

We can have basic blocks like simple text and paragraphs

We can have links to other pages, blog posts or people

we can have media (image, embeds, audio, video)

## Working with Blocks

You can copy and paste text, single blocks or multiple blocks

You can reorder blocks, you can edit and duplicate them

You can transform one block into another

## Layouts

Layout are blocks that arrange blocks inside a screen

They are useful when building a website

Most website can be built with predefined layout patterns

## Interactive Blocks

ObservableHQ let you have interactive blocks to document and play with data visualization

You could embed some code playground in your content to make them more interessant

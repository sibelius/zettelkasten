The standing ovation model represents how people behaves based on other people

for instance:

if there is a new fashion item in the market, only a few people will start using before everybody else

Other people needs to see 1 or N people using it before start using it.

The same goes to clap, you only start clapping after N people are clapping

what is your N? your N should be 0; try to start things

#atom #thoughts

We can use atom to describe something that is minimal and indivisible

We can have an atom of state like redux recoiljs

We can have an atom of thought as Roam and Zettelkästen uses

We can derive state using multiple atoms

We can compose thoughts ideas using many atoms

A [Mental Models](./mental-models) is an atom of thought, very well defined one.

We can have `atomic` [CSS](./css) , to compose our styles

Atoms are the building blocks ([The era of Content Builders](./the-era-of-content-builders) , [Where good ideas come from](./where-good-ideas-come-from)) of everything

In design you have colors, space, fonts are the basic atoms/blocks to mix and match content

Any creation process is easier if you not start from a "blank canvas"

When doing Writing it is better to start from writing pieces instead of pulling ideas out of your mind.

If you try to start writing directly from your mind, you need first to transform your mind ideas into text, and them combine them. Mind has a process as the ideas are not so structure, and also subjectivy

When starting coding, it is easier to start off from piece of code or boilerplate. It is easier to combine existing code with code that you're gonna build on the fly. Another benefit of using existing code, it the code worked before it has more changes to keep working now.

When doing design start with some basic elements, or existing design.

Modify to your requirements. It is much easier to combine pre-existent UI elements instead of drawing everything using a pencil.

What about creating a new music? or a remix? isn't it to start with some sounds and compose them?

What about video? you can have some set of images to compose in the video, some set of predefined animations, some set of short videos.

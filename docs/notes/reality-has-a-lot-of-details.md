Being realistic is to listen to reality, and learn all details of it.

It does not matter all your knowledge of your backend if you want to be productive in [CSS](./css)

CSS has a lot of details, so you need to learn, practice and learn all of them to be productive

Cooking has a lot of details, just reading the recipe won't make your a good meal

Books can't tell all the details

> Reading all blog posts about Server Side Rendering (SSR) is not enough to properly implement it in a production app. The same is valid for most of the development tasks, like setting up a react native project, fixing a webpack weird bug and so on. You need to get your hands dirty with "reality" to understand what tiny details that matter.

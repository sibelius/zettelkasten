Building Block

Core API of any package should be very tiny

A tiny API is easier to reason about it

A tiny API is easier to maintain

A tiny API is easier to learn

Add extensions points to your API to make it extensions and cover all user needs

a tiny API is easier to make new releases

a tiny API needs less tests

What should be the core API of react-native-camera?

take a picture

render picture preview

record a video

What about filters in the photo? another package

What about MLKit like face-detection and text detection? 2 new packages

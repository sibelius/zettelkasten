#issue #project #management

Issue is an [Atom](./atom) task.

It represent a chunk of work to produce something

It can represent a new feature that needs to be implemented

It can represent a bug that needs to be solved

It can represent an improvement

It can represent a technical debt that needs to be solved

You can add labels to issues (metadata) to making them easier to find, and also group them

You can also link other issues, pull requests, commits to add more context to the issue.

You can attach an issue to a temporal context using a milestone

A milestone represent a list of issues that should be worked in a given space of time

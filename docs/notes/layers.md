I think we can go from electrons to no-code to cover all layers and abstractions that you need to know, not master, to understand what it is really going on.

The basic building blocks of a CPU is the transistor.

A transistor let electric current pass given a following configuration.

So we have 0 and 1, binary. 0 is no current and 1 is current.

And everything is built on top of this concept.

Then we have boolean logic, that let us sum, subtract and to most math using binary code.

We use logic ports to create basic arithmetic.

If you add PC (program counter), a clock, you have a basic CPU.

If you can load data from memory and write to memory, you can do anything your modern computer does.

You can build your own assembly, then you decode each instructions and execute simple programs.

After that you could keep using assembly, or build a higher level language to compile to assembly to make your life easier, like C.

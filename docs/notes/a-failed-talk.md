A talk is a good way to explain some concept.

When doing a talk you need to know your audience, you can't target beginners and advanced users at once

A failed talk can happen for many reason

- wrong subject
- bad slides/content
- wrong audience targeting

Substack

There are no hard subjects to be cover in a presentation, there are only different ways of presenting them.

I did a “bad” talk at Rancho Dev when I’ve talked about Forms and Formik (slides and code here).

The problem of this talk was about my assumptions of the audience. I’m used to talking in places that most people know basic React concepts, but Rancho Dev conf was a more broad conferences with many different topics.

As I did not provide more context (a basic intro of React, react hooks and so on), it was hard to explain to them how to apply this concepts to solve the forms in React land. I always ask for feedback ( give me here) after my talk, and this one I received a really bad one saying that I thought the audience won’t grasp the concepts.

The truth was that I didn’t understand really well these concepts to explain like I’m 5.

How would be a better talk for that audience?

- More about the problem and motivation (how hard complex forms can be to get right)
- basic React intro concepts
- more concepts less code

MCP server

Ask me from your AI

Use my notes from Claude, Codex, Cursor or any AI tool that speaks MCP. Your assistant answers from what I wrote, with links, and sends me what I have not written about yet.

One file. Read-only. No dependencies, no account and no API key. It only needs Node.js 18 or newer.

Step 1

Download the server

macOS and Linux:

curl -fsSL https://sibelius.github.io/zettelkasten/sibelius-mcp.mjs -o ~/.sibelius-mcp.mjs

Windows (PowerShell):

Invoke-WebRequest https://sibelius.github.io/zettelkasten/sibelius-mcp.mjs -OutFile $HOME\.sibelius-mcp.mjs

It reads my notes from this site each time it starts, so you get new notes without downloading it again. Run the same command to update the server itself. You can read the code first.

Step 2

Your home folder

MCP config files need the full path to the file. Type your home folder and every command below uses it.

Find it with echo $HOME on macOS and Linux, or echo $HOME in PowerShell. On Windows, write it with forward slashes: C:/Users/you.

Step 3

Add it to your AI

Claude Code

  1. Add it for every project:

    claude mcp add --scope user sibelius -- node /Users/you/.sibelius-mcp.mjs

  2. Start a new session and run /mcp: sibelius shows as connected.

Claude Desktop

  1. Open Settings › Developer › Edit Config. That opens claude_desktop_config.json (~/Library/Application Support/Claude/ on macOS, %APPDATA%\Claude\ on Windows). Add:

    {
  "mcpServers": {
    "sibelius": {
      "command": "node",
      "args": [
        "/Users/you/.sibelius-mcp.mjs"
      ]
    }
  }
}

  2. Quit Claude Desktop completely and open it again. The tools show under the + button in a new chat.

Codex

  1. Add it from the terminal:

    codex mcp add sibelius -- node /Users/you/.sibelius-mcp.mjs

  2. Or add it to ~/.codex/config.toml, which the Codex CLI and the IDE extension share:

    [mcp_servers.sibelius]
command = "node"
args = ["/Users/you/.sibelius-mcp.mjs"]

  3. Run /mcp in Codex to check it is there.

Cursor

  1. Add it to ~/.cursor/mcp.json for every project, or .cursor/mcp.json for one:

    {
  "mcpServers": {
    "sibelius": {
      "command": "node",
      "args": [
        "/Users/you/.sibelius-mcp.mjs"
      ]
    }
  }
}

  2. Check it under Cursor Settings › MCP, then ask in Agent mode.

VS Code

  1. Add it from the terminal:

    code --add-mcp '{"name":"sibelius","command":"node","args":["/Users/you/.sibelius-mcp.mjs"]}'

  2. Or add it to .vscode/mcp.json in a project:

    {
  "servers": {
    "sibelius": {
      "type": "stdio",
      "command": "node",
      "args": [
        "/Users/you/.sibelius-mcp.mjs"
      ]
    }
  }
}

  3. Use it from Copilot Chat in Agent mode.

Gemini CLI

  1. Add it from the terminal:

    gemini mcp add --scope user sibelius node /Users/you/.sibelius-mcp.mjs

  2. Or add it to ~/.gemini/settings.json:

    {
  "mcpServers": {
    "sibelius": {
      "command": "node",
      "args": [
        "/Users/you/.sibelius-mcp.mjs"
      ]
    }
  }
}

  3. Run /mcp in Gemini CLI to check it is there.

Windsurf

  1. Add it to ~/.codeium/windsurf/mcp_config.json:

    {
  "mcpServers": {
    "sibelius": {
      "command": "node",
      "args": [
        "/Users/you/.sibelius-mcp.mjs"
      ]
    }
  }
}

  2. Refresh the MCP list in Cascade.

Others

  1. Any MCP client that runs local (stdio) servers works: Zed, Cline, Continue, Goose, LM Studio, Raycast and more. Most take this JSON in their MCP settings:

    {
  "mcpServers": {
    "sibelius": {
      "command": "node",
      "args": [
        "/Users/you/.sibelius-mcp.mjs"
      ]
    }
  }
}

  2. If yours asks for fields instead, the command is node and the only argument is the file path.

ChatGPT and Claude on the web only connect to MCP servers hosted on a URL, and this one runs on your computer. There, point the model at llms.txt or llms-full.txt, or use Ask Sibelius on this site.

Step 4

Try it

  • “Ask Sibelius how to become a senior engineer”
  • “Como faço pra conseguir meu primeiro emprego como Dev? Use o MCP do Sibelius”
  • “What has Sibelius been reading this week?”
  • “List the notes Sibelius wrote about mentorship”
ToolWhat it does
ask_sibeliusAnswers a question from what I wrote, with links. If I have not written about it, it says so and gives two links: one to ask me the question, one to ask me to write about it.
search_notesKeyword search over notes, public answers, posts and reading, or only one of them.
get_noteThe full text of one note.
list_notesNotes with a tag or in a section, like Mentorship.
recent_readingWhat I have been reading and sharing, newest first or on one day.

There is also a prompt, answer_as_sibelius, that answers in my voice. The server only searches what I wrote: it never makes up an answer, and nothing you ask is sent anywhere unless you open the GitHub link it gives you.

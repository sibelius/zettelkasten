#index #retrieving

Indexing is the art of making retrieving data faster

Elastic Search (lucene) uses an inverted index to retrieve all documents fast.

An inverted index is like this:

doc1 - Awesome

doc2: Alert

doc3: Beta

doc4: Crud

doc4: Create

A - doc1, doc2

B - doc3

C - doc4, doc5

It search based on prefix/suffix to reduce the search time

Zettelkasten is like an index for our brain, as we can find ideas/thoughts faster than using another method

we can search using tags, full text search and links among notes

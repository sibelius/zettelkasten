Workshop is a set of practical exercises so users really “taste” how to solve something

They need to struggle to solve at first to improve learning retaintion

Zoom has a breakout room divides the people of a workshop in many rooms so they can discuss in smaller groups while solving exercises

Kent has 3 types of workshops

  • set of exercises
  • fill parts of a complete app
  • build an app incrementally

Each exercise can have an extra credit for advanced students

You need to cap to 30/40 people per workshop so you can have time to help all students, more active learning instead of passing learning of a webinar

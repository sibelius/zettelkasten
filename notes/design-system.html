Design System

  • design
  • frontend

Updated Oct 24, 2026

Edit on GitHub

Design system contain the building blocks of UI elements/atoms to build your product UI

It should allow extensions using functional CSS

Design system should define list of fonts

Design system should define list of possible spacing (so everything is spaced with the same style)

Design system is about constraint, you limit what you can do to avoid creating weird UI, and keep consistency

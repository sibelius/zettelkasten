Updated Oct 24, 2026

Edit on GitHub

I’m known in open source mostly by my Relay contributions

I’m also know because of react-native contributions

Relay is a data fetching that scales, it let you declare which data each components needs, and it will get the data for you

Relay only works with GraphQL server, it has this hard requirements to make it possible to achieve their goals

Relay is made by Facebook and they work close to React team

I’m generating content about Relay since the beginning as the docs are “hard” to follow

My first contributions was most blog posts in medium, then I’ve made a bigger relay modern course that was more a set of slides.

React Europe invited me to give a workshop about new Relay apis, so relay workshop is a set of 12 exercises that teach most of the Relay concepts in a practical way building a social network.

I also gave a lighting talk about Relay concepts in less then 10 minutes

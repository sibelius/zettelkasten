Ethereum is like Bitcoin but with turing complete smart contracts

ECR-20 token

tokens only exist inside a contract

0eth to transfer token + gas fee

ecr-20 complaint - fungible (same value for each token, like money)

totalSupply, balanceOf, transfer, transferFrom, approve, and allowance. In addition, you can specify optional functions, such as name, symbol, and decimal

liquidity pool - unisawp - x * y = k (k constant, total liquidity)

eth ↔ erc-20 token

erc-20 ↔ erc-20 token

ERC-721 non fungible token - each token has a different value - property

erc-721 + erc-165 interface

erc - ethereum request for comment

proof of work - more energy wins

proof of stake - you stake (put some eth money), you someone is randomly assign to validate the block, if you cheat you loose your stack

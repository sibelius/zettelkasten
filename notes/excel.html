Excel is a software to process spreadsheet/tabular data

Excel can be think as one of the first Thinking Tools.

You put a lot of number, and start building thinks on top of it, using formulas per cell or Visual Basic Scripts.

The basic building block (Where good ideas come from , The era of Content Builders ) is the cell.

A cell can contain a basic type (string, number, currency, date)

A cell can contain formatting (background color, color, font-size and more)

You can span a cell to contain more than one column

You can use Excel to import (Importing data using csv / xlsx ) or export data.

Airtable is the new “Excel”. Acts likes a spreadsheet but gives you the power of a database

You can see the same data in different ways in Airtable: Calendar, Grid, Kanban, Gallery, Form
